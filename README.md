One single line of text — the message a smart fridge sends its owner at 3am.

> 3am. Your leftovers started a podcast in here and I'm the only subscriber. Please eat them before they get a sponsor.

A machine with a small voice, an opinion, and no shame about sharing it at 3am: it has been awake the whole time, it is the leftovers' only audience, and it would really like its owner to intervene before things escalate. No milk, no ice, no door-left-open — just a fridge that has decided this is the moment to speak.

## Run

```sh
python3 main.py
```

Writes exactly one line (117 characters) to `/output/entry.txt`.
